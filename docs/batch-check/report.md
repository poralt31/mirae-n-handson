## 계산 기준

- **7일 평균**: CSV 에서 그 job 의 직전 7개 기준일 중 행이 있는 날의 평균. 직전 7일이 모두 있는 것은 09-15 이후뿐이다(단 `build_item_stats` 는 09-09 행이 없어 09-15 · 09-16 은 6일 평균, 09-17 은 7일 평균). 09-09 ~ 09-14 는 있는 날(1~6일)만으로 평균을 냈고 30% 를 넘는 날은 없었다. 09-08 은 직전 데이터가 없어 건수 기준을 적용하지 못했다(0건은 아님).
- **교차 확인**: 로그 SUCCESS 의 `rows=` 와 CSV `row_count` 는 09-15 `load_datamart`(로그 184532 × 2, CSV 369064)와 09-09 `build_item_stats`(로그 SUCCESS 없음, CSV 행 없음)를 빼고 모두 일치했다.
- **평소 소요 시간**: 그 job 의 다른 날 소요 시간 중앙값. 소요 시간은 SUCCESS 줄의 `elapsed=` 값이고, `build_report_cache` 는 `elapsed=` 가 없어 START · SUCCESS 시각 차이로 계산했다.
- 실행 단위 추출과 시각 차이는 `awk` 로, 평균 · 중앙값 · 배수는 python 스크립트로 계산했다.
